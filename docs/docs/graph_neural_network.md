## 二、核心概念

### 什么是图神经网络

图神经网络（Graph Neural Network, GNN）是一种专门用于处理图结构数据的深度学习模型。

### 主要类型

1. **GCN (Graph Convolutional Network)** - 基于谱域的图卷积
2. **GAT (Graph Attention Network)** - 引入注意力机制
3. **GraphSAGE** - 采样与聚合
